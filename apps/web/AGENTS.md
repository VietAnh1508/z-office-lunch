# Web Frontend Conventions (`apps/web`)

When working in `apps/web/src/`, read and follow these project rules:

- [form-validation.md](../../.claude/rules/form-validation.md) — `useRequiredField` hook, `noValidate`, and inline field errors instead of native HTML `required`.
- [mutation-feedback.md](../../.claude/rules/mutation-feedback.md) — Sonner toast feedback wired into `useMutation` `onSuccess`/`onError` with static messages.
